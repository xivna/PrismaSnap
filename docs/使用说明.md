# PrismaSnap 使用说明

**版本**: 1.0.0 · **平台**: Windows 11 (x64) · **形式**: 便携版（解压即用，无需安装）

---

## 一、PrismaSnap 是什么

一款常驻系统托盘的 Windows 截图工具，特点：

- **HDR 友好**：系统开启 HDR 时截图不过曝、不发灰，与 Windows 自带截图的观感一致。
- **即时标注**：矩形、箭头、画笔、马赛克/模糊/纯色、文字，全部所见即所得。
- **AI 增强**：一键提取图中文字（OCR）、原位覆盖式翻译（译文直接渲染在原文字之上）。
- **本地优先**：AI 接口为 OpenAI 兼容格式，可接 llama.cpp / Ollama 等本地服务，数据不出机。
- **完全便携**：所有配置、日志、保存的截图都在程序目录内，不写注册表、不写系统文件夹。

---

## 二、安装与启动

1. 将 `PrismaSnap_1.0.0_portable.zip` 解压到任意目录（路径可含中文与空格）。
2. 双击 `PrismaSnap.exe` 启动。
3. 启动后**没有主窗口**，只有系统托盘图标；首次运行会自动在程序目录生成
   `config.toml`（设置）与 `logs/`（日志）。
4. 打开设置：**双击托盘图标**，或右键托盘图标选「打开设置」。
   - 设置窗口的位置与大小会被记住，下次打开时恢复。
5. 程序为单实例：重复启动会弹窗提示，不会出现两个托盘图标。
6. 退出：右键托盘图标选「退出」。

> **移动程序目录**：整个目录可随时剪切/复制到别处，配置与截图会跟着走。
> 注意退出程序后再移动，并在新位置重新启动。

**系统要求**：Windows 11 x64。使用 OCR 插件（ONNX 推理）时一般需要
Microsoft Visual C++ 运行库（Windows 11 通常已自带，缺失时安装
[VC++ 2015-2022 运行库](https://aka.ms/vs/17/release/vc_redist.x64.exe) 即可）。

## 三、快捷键

| 按键 | 作用 | 可自定义 |
| :--- | :--- | :--- |
| `Ctrl+Alt+A` | 触发截图（默认，可在设置中改） | 是 |
| `Esc` | 取消截图 / 退出标注拖动 / 关闭编辑 | 否 |
| `Enter` | 确认并复制到剪贴板 | 否 |
| `Ctrl+C` | 复制到剪贴板 | 否 |
| `Ctrl+S` | 保存到文件 | 否 |
| `Ctrl+Z` | 撤销标注 | 否 |
| `Ctrl+Shift+Z` / `Ctrl+Y` | 重做标注 | 否 |

修改截图热键：设置 → 通用 → 截图热键 →「重新录制」→ 按下新组合键（`Esc` 取消）。
修改后立即生效。

## 四、截图流程

1. 按 `Ctrl+Alt+A`：**鼠标所在显示器**全屏出现半透明遮罩，进入选区状态。
2. 按住左键拖动选择区域；`Esc` 取消。
   - 选区限制在当前显示器内，不支持跨屏。
3. 松开鼠标：出现所选区域的浮动预览窗口，鼠标附近弹出**工具条**。
4. 此时可直接：
   - `Enter` / `Ctrl+C`：复制选区到剪贴板并退出；
   - `Ctrl+S`：保存文件并退出；
   - 点击工具条上的「复制」「保存」「取消」同理；
   - 点击工具条的标注工具进入编辑（见第五节）。
5. 单击选区外的空白处可**重新框选**；拖动选区内部可整体平移选区。

> **保存行为**：在设置 → 保存 中选择「静默保存」（默认保存到 `<程序目录>/screenshots`）
> 或「每次询问」（每次弹出系统保存对话框）；格式支持 PNG / JPEG（可选质量）。

### 关于 HDR 屏幕

- 系统开启 HDR 时：**预览窗口**完整显示高光（所见即屏幕上原貌）；
  **导出/复制的图片**会映射为 SDR（与 Windows 自带截图行为一致）。
  因此预览与导出图存在亮度差异属于**预期行为**，不是 bug。
- 多显示器：每次只捕获鼠标所在的那一块屏，HDR/SDR 混合环境不会串色。

## 五、标注工具

点工具条上的工具图标进入标注模式，再次点击同一图标退出。

| 工具 | 用法 |
| :--- | :--- |
| **矩形** | 拖动框出矩形，用于框选重点 |
| **箭头** | 从起点拖向终点；拖得短时只画箭头头部 |
| **画笔** | 按住左键自由绘制 |
| **马赛克** | 拖动覆盖需要遮挡的区域；可选「像素化 / 模糊 / 纯色」三种效果，可调块大小或半径 |
| **文字** | 拖动拉出文本框后输入；`Enter` 提交（`Shift+Enter` 换行），`Esc` 取消；双击已有文字可再次编辑 |

通用操作：

- 工具条第二行可选**颜色**与**线宽**；文字工具另有**字体**与**加粗**。
- **无工具状态**下（未选任何工具）单击已有标注可选中并拖动；文字选中框支持八向缩放。
- `Ctrl+Z` 撤销，`Ctrl+Shift+Z` / `Ctrl+Y` 重做。
- 标注只作用于最终预览与输出图，不会修改原始截图。

## 六、提取文字（OCR）

1. 框选含文字的屏幕区域。
2. 点工具条「提取文字」。
3. 完成后**识别出的全部文字会直接复制到剪贴板**，状态行提示「已复制提取的文字」，直接粘贴即可使用。

- 识别使用内置的 Windows 系统 OCR，开箱即用；安装了 OCR 插件后自动升级为高精度引擎（见第九节）。
- 若系统缺少对应语言的 OCR 语言包，可在「Windows 设置 → 应用 → 可选功能」中添加。

---

## 七、翻译

1. 框选要翻译的文字区域。
2. 点工具条「翻译」。
3. 完成后**译文会直接渲染覆盖在原文字之上**（字号自适应、颜色随原文采样），
   状态行出现「复制译文」按钮——译文是图片像素不可选中，此按钮用于复制全部译文文本。

翻译引擎为你在设置中配置的 OpenAI 兼容 API（见下一节）。翻译模式：

| 模式 | 说明 | 适用场景 |
| :--- | :--- | :--- |
| **自动**（默认） | 按 OCR 置信度分流：有把握的走快速文本翻译，没把握的走多模态 | 大多数场景，无需操心 |
| **裁剪 → 多模态** | 每块区域裁图交给多模态模型识别+翻译 | 艺术字、Logo、透视变形文字 |
| **OCR 识别 → 文本翻译** | OCR 出文字后整段交给文本模型翻译 | 界面、聊天、代码、文档等标准字体，快且省 |

## 八、AI 接口设置（设置 → AI 接口）

### 8.1 基础 LLM（文本翻译后端）

| 项 | 说明 |
| :--- | :--- |
| API 地址 | OpenAI 兼容的完整地址，如 `http://127.0.0.1:8080/v1/chat/completions` |
| API Key | 本地服务可留空；云端服务填对应密钥 |
| 模型 | 模型名，如 `qwen3-8b` |
| 翻译目标语言 | 如「简体中文」「English」「日本語」 |

### 8.2 多模态 LLM

三选一：

- **与基础 LLM 相同**（默认）：多模态请求复用上面的地址/Key/模型（需该模型支持图片输入）。
- **不配置多模态大模型**：翻译模式「裁剪 → 多模态」不可选，「自动」退化为纯文本路径。
- **自定义**：单独填多模态服务的 URL / Key / Model。

### 8.3 大模型参数

- **启用自定义参数**（默认开）：开启时，下方 JSON 会逐键合并进每次请求；
  关闭时自动剔除思考相关四个键（`reasoning_effort` / `enable_thinking` /
  `chat_template_kwargs` / `think`），其余自加键不受影响。
- JSON 默认值：

  ```json
  {"temperature":0.2,"max_tokens":4096,"num_ctx":8192,
   "reasoning_effort":"none","enable_thinking":false,
   "chat_template_kwargs":{"enable_thinking":false},"think":false}
  ```

- 说明：各家服务端对「关闭思考」的参数支持不统一，这里组合多写几个键，服务端会忽略不认识的；
  若服务端报 400，试试关闭「启用自定义参数」。对 llama.cpp 老版本，需在**服务端启动参数**里关闭思考。
- JSON 输入框失焦时结算：合法则美化保存，非法则恢复上一版并红字提示。

### 8.4 提示词模板

高级选项：自定义「纯文本翻译」「多模态单图」「多模态批量」三条提示词。
保持默认即可；占位符说明见设置页提示图标。

### 8.5 OCR 引擎

- `auto`（默认）：装了插件用插件，没装用系统 OCR。
- `system`：强制系统 OCR。
- `rapidocr`：强制插件；插件缺失时识别不可用并提示。

## 九、OCR 插件（高精度识别，可选）

内置的系统 OCR 足以应对常规界面文字；对**小字、密集排版、艺术字**，
安装 RapidOCR 插件后识别效果显著提升。

### 方式一：设置页自动下载（推荐）

设置 → AI 接口 → 「OCR插件下载」，四行文件（`det.onnx`、`rec.onnx`、`keys.txt`、
`onnxruntime.dll`）各自独立操作：

- 缺失时点「下载」；下载中可「暂停」或「取消」；
- 暂停后点「继续」断点续传；取消会删除未完成文件；
- 模型下载完成后会校验 SHA256，不匹配会自动删除并重下；
- 四行都变绿即安装完成，**无需重启**。若替换过 `onnxruntime.dll`，则需重启程序。

### 方式二：插件包手动安装

如果你拿到的是 `PrismaSnap_1.0.0_OCR插件包.zip`：

1. 退出 PrismaSnap；
2. 将压缩包内的 `plugins` 文件夹解压到 PrismaSnap 程序目录（与 exe 同级，覆盖合并）；
3. 最终结构应为：`<程序目录>/plugins/ocr/det.onnx`、`rec.onnx`、`keys.txt`、`onnxruntime.dll`；
4. 重新启动程序，在设置页 OCR 引擎处确认状态为「插件已加载」。

> 插件包较大（约 47MB），主程序包保持轻量；不装插件不影响基础截图/标注/翻译（翻译走系统 OCR）。

## 十一、常见问题（FAQ）

**Q：截图在 HDR 屏幕上预览很亮，保存的文件却偏暗？**
这是预期行为：预览完整还原屏幕上所见（含 HDR 高光），导出文件按 SDR 标准映射，
与 Windows 自带截图一致。

**Q：翻译/提取文字失败或无响应？**
按顺序检查：① 设置页 AI 地址/Key/模型是否填写正确（可用「提取文字」验证 OCR 本身是否正常）；
② 本地服务（llama.cpp 等）是否已启动、端口是否对；③ 翻译模式「自动」需要多模态支持时
是否配置了多模态模型；④ 查看 `logs/` 目录下最新日志的报错信息。截图与标注功能不受影响。

**Q：译文没有出现？**
原始文字区域太小或模型返回异常时会跳过该区域；状态行会有失败提示。可换「裁剪 → 多模态」模式重试。

**Q：装了插件但 OCR 状态仍显示未加载？**
确认 `plugins/ocr/` 下四个文件齐全（文件名必须准确），且未误放在子目录。
若替换过 `onnxruntime.dll`，需要重启程序。

**Q：杀毒软件报毒/拦截？**
PrismaSnap 不含任何驱动与键盘钩子（全局热键走系统 `RegisterHotKey`），
如遇拦截请将程序目录加入白名单。

**Q：日志在哪里？**
程序目录下 `logs/`，按日期命名。反馈问题时附上日志有助于定位。

**Q：如何卸载？**
退出程序，删除程序目录即可，系统无残留（不写注册表）。

## 十二、文件与隐私

- `config.toml`：所有设置（含 API Key，明文保存在本机，请勿随意外发）。
- `logs/`：运行日志（含错误信息，不含截图内容）。
- `screenshots/`：默认静默保存目录。
- `plugins/ocr/`：可选 OCR 模型（卸载时一并删除）。
- 网络访问：仅在「提取文字 / 翻译」时访问你配置的 API 地址；程序自身不向任何服务器上传数据。
